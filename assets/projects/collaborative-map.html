01

Le contexte

MAP collaborative est mon premier projet académique utilisant PHP et une base de données SQL. L'objectif était de concevoir une application web complète et fonctionnelle, allant de l'interface utilisateur jusqu'à la gestion des données.

Le projet devait notamment intégrer une authentification, plusieurs pages dynamiques et des fonctionnalités collaboratives autour d'une carte.

02

L'objectif

01

Créer un compte

Permettre aux utilisateurs de s'inscrire et de disposer d'un espace personnel.

02

Sécuriser l'accès

Mettre en place une connexion et contrôler les différentes sessions utilisateur.

03

Collaborer

Ajouter, consulter et partager des informations depuis une carte commune.

03

La solution développée

J'ai développé une application full-stack structurée autour d'une interface web, d'un backend PHP et d'une base de données SQL. Les pages communiquent avec le serveur afin d'enregistrer les comptes, vérifier les connexions et récupérer les informations affichées sur la carte.

Ce premier projet full-stack m'a permis de comprendre comment les différentes couches d'une application communiquent entre elles. Il m'a également appris à structurer une base de données, gérer des sessions et transformer un besoin fonctionnel en une application utilisable.
